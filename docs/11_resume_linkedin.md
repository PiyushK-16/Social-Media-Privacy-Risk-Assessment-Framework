## C. LinkedIn project description
I built the **Social Media Privacy Risk Assessment Framework**, an educational, privacy-first tool that helps users understand how their settings and habits affect exposure. Users answer 44 choice-based questions (never typing phone numbers, e-mails or addresses). The engine calculates ten category scores and a weighted overall score (LOW to CRITICAL), lists ranked findings with IMMEDIATE / IMPORTANT / GOOD PRACTICE recommendations, and simulates how improving settings changes the score. A dashboard over 1,000 *synthetic* profiles, a printable report, a privacy checklist and a local EXIF metadata tool round it out. The project stores only scores and finding types, includes a threat model and risk matrix, and has 45 passing automated tests. It does not scrape, track or profile real people. Tech: Python, Flask, SQLite, JavaScript, Chart.js, pytest. Code and documentation on GitHub: [link].
